Política de privacidad

Esta política describe la aplicación personal Vigia Auditoria y distingue su circuito privado de esta web informativa.

1. Titular y finalidad

Daniel mantiene esta herramienta para organizar y revisar sus propios informes de simulación de estrategias de criptomonedas. Contacto: daniel2a2d@gmail.com. No se admiten cuentas de terceros ni se ofrece un servicio público de gestión de inversiones.

2. Datos a los que accede la aplicación

  • Metadatos de archivos y carpetas de Google Drive: identificadores, tipo, estado, permisos, propietario y capacidades necesarios para comprobar el destino documental.
  • Contenido de documentos de auditoría y respuestas: informes, contexto, observaciones, hipótesis y propuestas de revisión.
  • Objetos de Cloud Storage y sus metadatos: manifiestos, generaciones, tamaños, huellas de integridad y registros del circuito.
  • Registros técnicos y de simulación utilizados por los componentes de auditoría, incluidos estados, fechas y resultados del procesamiento.

Los permisos OAuth consentidos pueden ser más amplios que los archivos usados por el programa. La selección por identificadores y las comprobaciones del código no constituyen una restricción del permiso OAuth a esa carpeta. Esta web no recibe tokens OAuth ni solicita acceso a Google.

3. Uso de los datos

Los datos se utilizan para comprobar integridad y coherencia, preparar documentos privados, registrar opiniones y detectar incidencias del circuito. Cuando se habilitan los pasos de escritura, pueden crearse documentos y registros de retorno; las pruebas de sólo lectura no realizan esas acciones.

Las propuestas son material de revisión. No modifican automáticamente estrategias, no acreditan rentabilidad y no autorizan operaciones reales.

4. Proveedores y transferencias

  • Google: Apps Script, Drive, Docs y Google Cloud procesan y almacenan los datos necesarios para ejecutar y registrar el circuito privado.
  • OpenAI / ChatGPT: cuando el titular usa la conexión autorizada de Drive para la revisión asistida, el contenido documental seleccionado se comunica a ese servicio. No se trata de procesamiento exclusivamente local. Su tratamiento depende también de las condiciones y controles de datos de la cuenta utilizada.
  • Telegram: cuando se autoriza el envío, el resumen del resultado se comunica al bot y chat configurados. Se conserva evidencia técnica del intento y del resultado. Preparar un aviso no demuestra que se haya enviado.

El titular no vende estos datos ni los utiliza para publicidad. El acceso a datos de Google se destina a las funciones de auditoría descritas; no se autoriza su uso para entrenar modelos generalistas. Antes de habilitar una integración se deben revisar sus condiciones y controles de datos. Esta descripción no garantiza por sí sola la configuración de cada proveedor.

El uso de datos recibidos de las API de Google debe respetar la Google API Services User Data Policy, incluidos sus requisitos de uso limitado cuando correspondan.

5. Almacenamiento, conservación y eliminación

Los documentos y registros permanecen en los servicios configurados por el titular y pueden existir exportaciones privadas de trabajo. Actualmente no se garantiza una eliminación automática a un plazo fijo. La conservación de evidencias y las restricciones de borrado de cada almacenamiento deben revisarse antes de eliminar datos.

El titular puede detener los componentes programados, revocar las conexiones y gestionar la eliminación de sus documentos y objetos. Revocar el acceso no elimina copias ya guardadas ni datos previamente enviados a otros proveedores; éstos deben gestionarse por separado. Las solicitudes relativas a datos pueden dirigirse al correo de contacto, sin adjuntar secretos.

6. Seguridad y control de acceso

El diseño incorpora comprobaciones de privacidad, integridad y versión, permisos de servicio y separación entre lectura, escritura y entrega. Estas medidas no garantizan seguridad absoluta ni limitan por sí solas los permisos generales concedidos a una cuenta. Las credenciales y los documentos privados no forman parte de esta web pública.

La autorización de Google se puede revisar y revocar desde las conexiones de la cuenta de Google. También deben revisarse las conexiones de los demás servicios y cualquier programación activa.

7. Datos de los visitantes de esta web

El código de esta web no añade cookies, analítica, formularios, fuentes remotas ni almacenamiento en el navegador. El alojamiento previsto es GitHub Pages. GitHub puede tratar datos técnicos de las peticiones, como dirección IP, fecha o agente del navegador, conforme a su declaración de privacidad. Abrir un enlace externo o escribir al correo de contacto implica utilizar el servicio correspondiente.

8. Cambios

Esta política deberá actualizarse antes de incorporar nuevos usos, destinatarios o funcionalidades que cambien el tratamiento descrito. La fecha de versión permite identificar el texto vigente.
